# Chess Engine

Собственный шахматный движок на C++ с графическим интерфейсом на Python/Pygame.

Проект разрабатывается в рамках научно-исследовательской работы.

## Цель

Разработать собственный шахматный движок, способный анализировать позиции и выбирать ходы, а также исследовать влияние различных алгоритмов поиска и методов оценки позиции на игровую силу движка.

## Технологии

* **C++** — шахматный движок
* **Python** — графический интерфейс
* **Pygame** — визуализация
* **CMake** — сборка C++ части
* **Git** — контроль версий
